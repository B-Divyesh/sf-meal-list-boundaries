# Demo sandbox

Open [`/demo`](https://meal-list-boundaries.sociobot.in/demo) or select **Try it with sample data** on the first screen.

The demo starts with Home and Cabin shopping lists and four realistic meals: Pasta night, Taco bowls, Cabin soup, and Trail breakfast. It uses the `demo:planner` IndexedDB record, never reads the real `planner` record, and clears the demo record when **Start for real** is selected. **Reset demo** replaces the demo record with the shipped sample.
